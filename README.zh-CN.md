# YouTube Digest — 多语言与多 AI

[English](README.md) | [简体中文](README.zh-CN.md)

一个用于将 YouTube 视频转换为多语言学习与阅读资源的 Chrome 扩展。

YouTube Digest 提供字幕获取、翻译、双语阅读、AI 视频分析以及带时间戳的笔记功能。支持多种源语言、目标语言以及多个 AI 服务商。

## 功能

### 多语言字幕

- 尽可能自动识别视频的原始字幕语言。
- 支持字幕服务提供的视频原生字幕语言。
- 源语言不限于英语、中文或葡萄牙语。
- 用户可以手动选择视频提供的其他字幕语言。
